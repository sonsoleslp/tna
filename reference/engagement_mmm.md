# Example Mixture Markov Model Object for the `engagement` Data

A `tna_mmm` object structurally equivalent to a fitted seqHMM mixture
Markov model, used by the package's examples for
[`group_model()`](https://sonsoles.me/tna/reference/group_model.md) and
[`mmm_stats()`](https://sonsoles.me/tna/reference/mmm_stats.md).
Generated deterministically by
[`random_tna_mmm()`](https://sonsoles.me/tna/reference/random_tna_mmm.md)
with engagement-flavored state labels and three clusters; carries no
foreign class references so it is safe to bundle.

## Usage

``` r
engagement_mmm
```

## Format

A `tna_mmm` object containing three clusters over the states
`"Engaged"`, `"Moderate"`, `"Disengaged"`.

## Source

Generated by `data-raw/engagement_mmm.R` using
[`random_tna_mmm()`](https://sonsoles.me/tna/reference/random_tna_mmm.md).

## Details

Re-generate via `data-raw/engagement_mmm.R` whenever the simulator
changes.
